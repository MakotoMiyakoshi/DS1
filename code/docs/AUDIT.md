# DS1 development migration audit, 2026-11-12

## Confirmed author decisions

- This newly created `DS1` repository supersedes the deleted earlier DS1 repo.
- A previously discovered nearest-surface geometry error required replacement of the `p0300` distance/angle calculations with the author's corrected `p1300_estimateDipDepth.m`.
- For overlapping scripts, larger p-number normally denotes the final version. Figure 7 uses p1341, Figure 8 uses p1400, and the separate reference-axis diagnostic uses p1322.
- Leipzig and Dortmund ASR preprocessing use **BurstCriterion=20 SD**. The Dortmund archived single-loop 25-SD variant is obsolete.
- Top-level `README.md` is the author's explicit usability exception to TRACE's root rule.

## Corrected geometry provenance

The prior triangle nearest-point calculation had (1) reversed barycentric weights on BC and (2) an incorrect origin `[0 0 0]` fallback in some vertex regions. The supplied p1300 stage calculates closest points over cortical triangles and signed distances with multi-axis ray parity. Its computed local vertex-interpolated normals and dipole moment axial angles are the source of Figure 7 and Figure 8. Do **not** substitute any p0300 outputs. The corrected pipeline uses `p1300_estimateDipDepth/dipoleGeometry.mat` as its single geometry declaration of dependency.

Supplied recent source files preserved by the author outside the active repo: p1300, p1310, p1320, p1321, p1322, p1330, p1340, p1341, p1400. The public active pipeline includes p1300, p1310, p1322, p1341, p1400 only. Original code ZIPs are retained separately; no historic generated outputs have been modified by hand.

## Outstanding verification / limitations

1. **MATLAB was not available for an end-to-end run** on original data. These stages have been statically inspected, but their numerical results and final submission figures have not been independently regenerated here.
2. The new p1300 needs `p0210.../corticalMask.mat` plus aligned IC-level outputs from both datasets. Verify that those upstream data are generated identically to the corrected manuscript's analysis.
3. `p1300` flags ray parity conflicts, mesh degeneracy, barycentric reconstruction error and IC indexing errors; only observed zero-conflict runs count as passing these tests.
4. `p1400` asserts the manuscript's expected cortical groups (surface 2,873, deep 7,656, subcortex 4,049; classified total 14,578 and unclassified 218). These are expected values from the author's code, **not newly recalculated or validated values** in this environment.
5. EEGLAB, AMICA, FieldTrip, `fitTwoDipoles`, ribbon toolbox, and legacy plotting dependencies are not fully frozen/installed. Versions may differ by stage; verify the actual historical code and executed settings before describing the pipeline as bitwise deterministic.
6. Existing population arrays may preallocate N×62 or N×64 rows. Inspect trailing rows and IC-level alignment before interpreting these results or changing row handling.
7. The non-GUI UDL simulation code is migrated from a previous development snapshot and has not yet been shown numerically equivalent to the author's original GUI simulation; use the supplied regression CSV and recorded tolerances in `code/tests/`.
8. Original raw datasets and upstream `.set`/`.mat` files are not redistributed, and no checksum inventory of them is available here.
9. Figure numbers and captions should be checked against the final Cortex manuscript: p1322 is a sensitivity comparison, **not** the joint depth-angle Figure 8 generated by p1400.
10. All p-numbered stages should complete unattended with output exclusively in their own matching directory; inspect runtime artifacts after the first clean full run.

## Static inspection (not execution)

A fresh source inventory, required p-number dependency check, root-layout check, named-script check, and SHA256 list are available under `code/docs/`. Static success is not evidence of numerical reproducibility.
